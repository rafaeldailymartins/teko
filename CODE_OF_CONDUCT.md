# Code of Conduct

Tekó adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its code of conduct. The full text is maintained by the Contributor Covenant project at that
address and applies to this project as if reproduced here.

## Scope

It applies to every project space: issues, pull requests, discussions, code review, commit
messages, and any other channel where someone represents the project.

## Reporting

The project has no dedicated mailbox. To report unacceptable behavior privately, use GitHub's
[private reporting](https://github.com/rafaeldailymartins/teko/security/advisories/new) on this
repository (**Security** tab → **Report a vulnerability**) and start the title with
`[Conduct]`. The report is visible only to the maintainers; it is handled as a conduct report and
closed without publishing an advisory.

Reports are acknowledged within 72 hours. All reports are reviewed promptly and fairly, and the
maintainers respect the privacy and safety of the reporter. Enforcement follows the Contributor
Covenant enforcement guidelines (correction, warning, temporary ban, permanent ban).
